Parameter Perhitungan

  • Ketik nama parameter di formula, lalu pilih dari autocomplete (Ctrl+Space) atau Parameter Palette.

Operator Dasar

+, -, *, /, ( )

Fungsi Umum

sum(a,b,...), min(a,b), max(a,b), round(x,2)

Contoh
  • = Panjang Dinding * Lebar Dinding * Tinggi Dinding
  • = (Panjang + Lebar) * 2
  • = max(Tebal 1, Tebal 2) * Luas
Parameter ditampilkan sebagai chip/tag di editor formula.
